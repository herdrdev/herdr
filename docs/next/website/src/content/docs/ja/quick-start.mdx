Shepherd をまだインストールしていない場合は[インストール](/ja/docs/install/)を参照してください。その後、任意のプロジェクトディレクトリから Shepherd を起動します:

```bash
shepherd
```

Shepherd はデフォルトのバックグラウンドセッションを起動するか、それにアタッチします。ソケットを管理する必要はありません。デタッチしてもエージェントは動き続けます。

## ワークスペースを作成する

セッションにワークスペースがない場合、Shepherd は自動的にひとつ開きます。ワークスペースはタブ、ペイン、エージェントを入れるプロジェクト単位のコンテナです。アクティブなプロジェクトごとに専用のワークスペースを作ってください。そうすることでサイドバーのエージェント状態が読みやすくなります。

## マウスを使う

Shepherd はマウスネイティブなので、まずはクリックから始めてください。ペイン、タブ、ワークスペース、エージェントをクリックしてフォーカスします。分割境界をドラッグしてリサイズします。右クリックでコンテキストメニューが開き、ペインの分割やタブの作成ができます。テキストをドラッグ選択するとクリップボードにコピーされます。トークンをダブルクリックすると選択し、2 回目の押下を保持してドラッグすると単語単位で選択を広げられます。どちらもマウスを離すとコピーされます。コピーに Ctrl+C は不要です。

ターミナルが修飾キー付きクリックを Shepherd に渡す場合、Ctrl+クリックでペイン内のリンクを開けます。OSC 8 ハイパーリンクと `http://` または `https://` の URL に対応し、折り返されたリンクの先頭や末尾が表示範囲外でも開けます。Ctrl を押しながらリンク上にポインターを移動すると、表示中の部分に下線が付きます。ポインターを外す、ペイン内容が変わる、または Ctrl の解放イベントを受け取ると下線は消えます。一部のターミナルでは、修飾キーの変化はマウス移動時にだけ報告されます。

`ui.mouse_capture = true`（既定値）では、Shepherd が Ctrl+クリックを処理します。有効なプラグインがリンクに一致すると、先に実行されます。ハンドラーの起動に失敗するとエラーを表示して停止します。一致しない `http://` と `https://` のリンクは、Shepherd クライアントが動くマシンの既定ブラウザーで開きます。その他のリンクには一致するプラグインが必要です。このモードでは明示的なハイパーリンクを外側のターミナルに渡さないため、ラベル付きリンクをネイティブ操作で開けません。macOS の Command+クリックも同様です。

`ui.mouse_capture = false` では、明示的なハイパーリンクを外側のターミナルに渡します。そのターミナルの通常のショートカットと警告が使われ、Shepherd のプラグインは実行されません。キャプチャを無効にすると、タブのクリックや分割境界のドラッグなど、Shepherd のマウス操作も無効になります。

Windows Terminal は表示テキストから検出した URL を先に開く場合があります。それらを確実にプラグインへ渡すには、Windows Terminal の `settings.json` で `"experimental.detectURLs": false` を設定してください。全プロファイルに適用されます。Shepherd はこの設定を変更しません。

`ui.right_click_passthrough_modifier` を設定すると、その修飾キー + 右クリックで、右クリック・ホールド・ドラッグのジェスチャーがマウスレポーティング対応のペインアプリに送られます。

## エージェントを動かす

ペインの中でコーディングエージェントを起動します:

```bash
claude
```

`codex`、`pi`、`opencode` など、他の[対応エージェント](/ja/docs/agents/)でも構いません。Shepherd は自動的に検出します。サイドバーには各エージェントが `working`、`blocked`、`done`、`idle` のどれかが表示されます — すべてのワークスペースを横断して表示されるので、どのプロジェクトがあなたを必要としているか常に分かります。

## キーボード操作

キーボード操作は任意です。マウスですべての操作ができます。`ctrl+b` を押してプレフィックスモードに入り、アクションキーを押します。

よく使うアクション:

| アクション | キー |
| --- | --- |
| 右に分割 | `prefix+v` |
| 下に分割 | `prefix+minus` |
| 新しいタブ | `prefix+c` |
| 次 / 前のタブ | `prefix+n` / `prefix+p` |
| ワークスペースナビゲーション | `prefix+w` |
| 新しいワークスペース | `prefix+shift+n` |
| クライアントをデタッチ | `prefix+q` |

プレフィックスの考え方が初めてなら、[キーボード](/ja/docs/keyboard/)でプレフィックスとは何か、なぜマルチプレクサがこれを使うのか、プレフィックスなしで運用する方法を説明しています。Shepherd 内で `prefix+?` を押すとすべての有効なバインドが表示され、`prefix+[` でコピーモードに入ってキーボードからコピーできます。

## デタッチして戻ってくる

`prefix+q` を押すか、単純にターミナルウィンドウを閉じてください。Shepherd サーバーとすべてのエージェントは動き続けます。もう一度 `shepherd` を実行すると同じセッションに再アタッチします。

セッションを本当に終了してペインを停止するには:

```bash
shepherd server stop
```
