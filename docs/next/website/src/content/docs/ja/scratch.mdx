---
title: Scratch
description: Markdown メモと全画面ライター。
---

トップバーの **✎ scratch** でライターを開きます。変更は自動保存され、フッターに単語数と保存状態が表示されます。
**Esc** でメモ一覧、**Enter** で開く、**n** で新規、**s** で同期の切り替え、**d** で確認付き削除です。一覧で Esc を押すとターミナルに戻ります。

inbox の上の **Notes** は最新の 3 件を表示します。**▸ N more** で展開、**＋** で新規作成します。**⇅** は Zen writer と共有するメモです。

```toml
[scratch]
dir = "~/workspaces/personal/vault/Scratch"
```

既定のフォルダーです。`~` はホームディレクトリに展開されます。メモは Markdown ファイルです。
ローカルメモは `.local` に保存されます。同期を有効にすると共有フォルダーに移動し、frontmatter に `sync: true` が追加されます。
無効にすると `.local` に戻ります。Scratch はネットワーク通信を行いません。他の frontmatter は保持されます。
外部編集は一覧に反映され、保存の競合は上書きせずエラーとして表示されます。
